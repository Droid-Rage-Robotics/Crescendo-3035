# Team 3035 Robot Code — 2024 Season

## Overview

This repository contains the competition code for Team 3035's 2024 FRC robot, **Dissonance**, built for the **Crescendo** season.

---

## Season Summary

The 2024 season saw Team 3035 compete at two FIRST in Texas district events and the District Championship.

### Events Attended

* FIT District Waco Event
* FIT District Channelview Event
* FIRST in Texas District Championship — Apollo Division
* Daly Division
